# AetherFlow Community Wallpapers

This repository is the community wallpaper database for [AetherFlow](https://github.com/yashpreeto7/aetherflow), an ultra-lightweight live wallpaper engine for Windows.

## How It Works

- **Browse:** All AetherFlow users can browse community wallpapers directly in the app's Marketplace tab.
- **Submit:** Logged-in users can submit wallpapers through the app — no GitHub knowledge needed.
- **Approval:** Every submission is reviewed before going live.
- **Install:** One-click install from the Marketplace into your AetherFlow Library.

## Submitting a Wallpaper

1. Open AetherFlow
2. Go to **Marketplace → Submit**
3. Fill in the form (title, description, tags, URL or image)
4. Click **Submit for Review**

That's it! Your wallpaper will appear in the marketplace after review.
